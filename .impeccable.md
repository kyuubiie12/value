# Mentor — design context

## Design Context

### Users
Danish football bettors who already place bets and want an edge. They open the app
in short, focused sessions — scanning the value feed for spots where a bookmaker's
price sits above fair odds, checking how their tracked bets are doing, glancing at
the public track record. Often on a phone, sometimes late in the evening. They are
numerate and skeptical: the product only works if the numbers look trustworthy.
**It is an analysis / tracking tool — it never places bets.**

### Brand personality
Three words: **sharp, grounded, quietly confident.** Not hype, not "crush the
bookies" — more like a well-run trading desk. Plain Danish, no exclamation marks,
no "elevate / seamless / game-changer". Numbers do the talking.

### Aesthetic direction
- **Dark by default** (bettors, evening use, data density) with an opt-in light
  theme + four accent colours + five display fonts, all user-selectable on the
  profile. Emerald accent is the default.
- Competitor-informed but calmer: big `--font-mono` tabular odds paired with a
  compact brand-coloured bookmaker mark; a sporty display face
  (Space Grotesk default) for headings and fixture names; Geist for body.
- Off-black surfaces (`#090b11`), one cool-gray text family, a single faint
  ambient accent glow behind the page. Shadows tinted with the background hue.
- Anti-references: neon-on-black "AI dashboard", purple→blue gradients, glass
  everything, three identical feature cards, gradient text.

### Design principles
1. **Calm density.** Show a lot without shouting. Reduce borders and boxes;
   lean on spacing, weight and alignment for structure. Not everything needs a card.
2. **The number is the hero.** Odds, EV, yield, CLV — large, tabular, aligned in
   columns. Everything else supports it.
3. **Accent is rare.** ~10% of visual weight. Primary colour marks value and the
   one main action per view; never decorates.
4. **Semantic tokens only.** `bg-surface` / `text-muted` / `text-positive` /
   `bg-primary/12` from `globals.css` `@theme` — never raw slate/hex — so light,
   dark and every accent stay correct.
5. **Trust is a feature.** Track-record proof is always one glance away; every
   posted pick is followed and settled in public.

### Constraints
Next.js 16 App Router, React 19, Tailwind v4 (`@theme`, non-inline). No
`backdrop-blur` on repeated elements (scroll paint bugs). `<html>`/`<body>` use
`min-height`, never fixed `height`. Respect `prefers-reduced-motion`. See
`AGENTS.md` for the full convention list.
